# QA 标准

## 1. 三类 QA

### Geometry QA

检查尺寸、单位、闭合路径、刀线/折线关系、出血、安全区、重叠和容差。必须输出数值结果、输入哈希和失败项。

### Visual QA

检查文字可读性、层次、裁切、对齐、颜色观感和视觉缺陷。截图只能说明所见画面，不能证明源文件工艺正确；必须标注截图尺寸、来源和检查者。

### Production QA

检查颜色配置、专色映射、白墨/烫金/UV/击凸工艺对象、字体/链接资源、输出格式、文件完整性和印厂约束。缺少供应商确认时不能 PASS。

## 2. 证据包

每个 Gate 的证据包至少包含：

- Git commit SHA、工作分支和变更文件列表。
- 完整命令、退出码、测试数量和时间。
- 输入/输出文件路径与哈希；敏感值只记录存在性和掩码状态。
- 已知限制、失败项、人工裁决和下一步。

## 3. 独立性

生成者不能单独宣布自己的结果通过。Reviewer 只接受可复核文件和输出；如果只能看到截图、摘要或模型自述，结论最多为 REVIEW_REQUIRED。
