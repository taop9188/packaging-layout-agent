## 请求验证规则

先做一次最小请求；失败时收集错误码、请求地址、模型 ID、耗时和上下游状态，不能直接重复。修复后才允许执行 3 次连续最小请求和 1 次正常代码任务。任何 Key 都不能出现在请求日志、命令行或证据文件。

## P1 以后

Mac Worker、Adobe 真机、视觉 QA、压力测试和 24/7 运行不属于本次测试。它们必须在对应 Stage Gate 中建立独立夹具和人工验收，不得用 P0 的标准库测试代替。
