# 印前与工艺规则

状态：规则冻结，P0 不产生真实印前文件。

## 1. 颜色

- 印刷对象必须明确 ICC/颜色配置、CMYK 数值来源和转换责任。
- 专色必须有唯一名称、来源和输出映射；不能把屏幕近似色当作专色证据。
- 白墨、底白、局部上光、烫金和击凸必须是显式工艺对象，不能只写在自然语言备注中。

## 2. 几何

- 刀线、折线、出血、安全区和成品边界必须分层并可测量。
- 版面输出前必须检查闭合路径、自交、重复线、最小间距和超出安全区的内容。
- 单位、缩放比例和画板尺寸必须在文件与 QA 记录中一致。

## 3. 生产可行性

工艺规则必须以供应商或印厂可执行的规格为准。未知设备、材料、最小线宽、套印容差或后加工限制时，状态为 BLOCKED，而不是使用经验值冒充确认值。

## 4. P0 边界

本文不验证任何真实供应商参数，不创建 CMYK/专色样张，不输出 PDF/AI/PSD，也不声称满足某一印厂的印前要求。真实生产验证属于 P10 及之后的独立 Gate。
