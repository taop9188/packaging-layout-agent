# Adobe 自动化标准

状态：接口原则冻结，P0 不启动 Adobe。

## 1. 后续控制原则

- Illustrator 与 Photoshop 必须有明确的应用版本、文档版本和输入输出路径。
- 每次操作前保存可恢复副本，记录任务 ID、操作序列、开始/结束时间和输出哈希。
- 操作必须是幂等或可检测重复执行；未知状态时停止，不继续点击。
- 只允许在专用工作区创建派生文件，原始文件只读。

## 2. 失败处理

应用未响应、文档未打开、颜色配置不匹配、图层语义不完整、保存失败或输出哈希不一致时，任务必须进入 BLOCKED/RECOVERY。不得以截图或 UI 文字代替文件存在和内容校验。

## 3. P0 禁止项

P0 不安装插件、不启动 Adobe 自动化、不发送 AppleScript、不读写用户现有 Adobe 文件、不创建模拟 AI/PSD 产物。P1-P3 必须另行通过能力、权限和真机验证。
